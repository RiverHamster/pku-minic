求解支配关系
- dom(i, j): i 是否被 j 支配

求解 DF(i): i 的支配边界
- 直接枚举 j 计算即可，$n^2$

找到所有的可转 SSA 变量 x
- alloc，且分配的类型是指针或 i32

遍历 bb，标记出每个变量被定值的 bb 集合

对于每个变量，求解支配边界的并集，并标记这些 bb 需要加入该块参数

为每个块创建一个带块参数的新块，并建立原块到新块的映射

DFS 原 bb 的 DFG
- 维护每个 alloc 对应的 value
  - 遇到 alloc/store，替换 value，并且删除
  - 对于有块参数的块，替换 value
  - 遇到 load，直接替换成记录的值

SSA 的例子：
```c
int main() {
  if (cond) { int b = 1; }
  return 0;
}
```
显然 `if` 之后的 BB 不需要任何参数，但确实是对 `b` 定值的 BB 的支配边界。

```c
int main() {
  int a;
  if (true) { a = 1; }
  return a;
}
```
`if` 之后的 BB 需要一个参数 `a`，但在不使用优化时，无法得出 `a` 一定被定值的结论，也就是说存在路径使得 `a` 未定值。我们此处采取解决方案是为在这种情况下传入 `undef`。
